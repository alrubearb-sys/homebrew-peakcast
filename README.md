# Homebrew tap for Peakcast

Mountain weather in the menu bar. On a Mac with Apple Silicon:

```
brew tap alrubearb-sys/peakcast
brew trust alrubearb-sys/peakcast
brew install --cask peakcast
```

The app starts at once and, from then on, at login. Update it with `brew upgrade --cask peakcast`.

The cask is updated by the release workflow of [peakcast](https://github.com/alrubearb-sys/peakcast).
